# IMAT6 website

The marketing site for IMAT6, the IMAT study app for iPad, iPhone and Mac.

It is a plain static site (HTML, CSS, JavaScript and images), so it needs no build step to host.

| Page | File |
|---|---|
| Home | `index.html` |
| How it works | `how-it-works.html` |
| Devices | `devices.html` |
| FAQ | `faq.html` |
| Compare | `compare.html` |

## Hosting on GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)** → Save.
The site appears at `https://mufaddalmanaquib.github.io/IMAT-6-Website/` within a few minutes.
